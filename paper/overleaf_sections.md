## Research question

Does an agentic MoE on the Mistral API improve token compliance, responsive Carbon structure, and WCAG violation counts vs unconstrained Mistral and GPT-4o on five IBM Carbon tasks?

## Metrics

1. Token compliance %
2. Structure similarity + responsive props
3. axe-core violations (1440 / 375)
4. Latency / token cost

## Threats to validity

Small prompt set (n=5), API model drift, automated graders ≠ human taste.

See also `discussion_edge_cases.md`.
